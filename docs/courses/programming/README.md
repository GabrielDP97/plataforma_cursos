## Cómo Usar Este Curso

1. **Avanzar por fases**: completar una fase antes de pasar a la siguiente.
2. **Cada módulo es autónomo**: contiene teoría, ejercicios y una práctica.
3. **Dominio coherente**: el dominio Alumno/Curso/Matrícula se mantiene durante todo el curso.
4. **Proyecto final**: el módulo 15 integra todos los conceptos en un Sistema de Gestión de Notas.
