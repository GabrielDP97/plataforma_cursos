# Certificates

Proof of completion. Motivation for students. Marketing for platform.

---

## What Is a Certificate?

A document that confirms a student completed a course. It's a reward, a credential, and a marketing tool.

---

## Certificate Data

### Certificate Contains

- Student name
- Course name
- Instructor name
- Completion date
- Platform name/logo
- Unique certificate ID
- Optional: completion grade/score
- Optional: course duration

### Certificate Format

**MVP:** PDF download
**POST-MVP:** Shareable link, LinkedIn integration, badge system

---

## Certificate Generation

### When Is a Certificate Generated?

When a student completes a course. "Completing" means:

1. All lessons marked as complete
2. All required exercises submitted and reviewed — POST-MVP
3. All required quizzes passed — POST-MVP
4. Minimum course completion percentage reached (configurable, default 100%)

### MVP Certificate Generation

**Auto-generated PDF** when:
- All lessons in course are marked complete
- Student clicks "Complete Course" button (or automatic when 100%)

### POST-MVP Certificate Generation

More sophisticated rules:
- Minimum score on final assessment
- Minimum exercises completed
- Attendance in live classes (if applicable)
- Instructor approval required

---

## Certificate Storage

**MVP:**
- PDF stored in platform
- Student can download from profile
- Certificate ID for verification

**POST-MVP:**
- Shareable URL (publicly verifiable)
- LinkedIn credential export
- Open Badges standard
- Blockchain verification — FUTURE

## Certificate Verification

### MVP Verification

- Certificate has unique ID
- Anyone with ID can verify on platform
- Verification page shows: student name, course, date, status (valid/revoked)

### POST-MVP Verification

- Public verification URL
- QR code on certificate
- API for third-party verification

## Certificate Revocation

### When Can a Certificate Be Revoked?

- Academic dishonesty
- Plagiarism in exercises
- Violation of platform rules
- Instructor request (approved by admin)

### Revocation Process

1. Admin reviews case
2. Revokes certificate
3. Student notified
4. Verification page shows "Revoked"
5. Reason logged (internal)

## MVP Recommendation: NO CERTIFICATES

**Certificates should NOT be in MVP. Here's why:**

### Reason 1: No Completions Yet

Without exercises and quizzes, "completion" is just watching videos. A certificate for watching videos isn't meaningful.

### Reason 2: Motivation Without Certificates

Students are motivated by:
- Learning new skills
- Building projects
- Career advancement
- Personal satisfaction

Certificates are nice-to-have, not need-to-have.

### Reason 3: Design Work

Good certificates require design work. Templates, branding, layout. That effort is better spent on core features.

### Reason 4: Simple Alternative

Instead of certificates, show:
- Course completion status
- Progress history
- Completion date
- "Share your achievement" social media button (POST-MVP)

---

## When to Add Certificates

Add certificates when:
1. Courses have meaningful completion criteria (exercises, quizzes)
2. Students are actually completing courses
3. There's demand for credentials
4. The platform has enough courses to make certificates valuable

**Estimated phase:** POST-MVP (Phase 3-4)

---

## Certificate Alternatives for MVP

Instead of formal certificates, MVP can show:

1. **Completion badge** — Checkmark on profile showing course completed
2. **Completion date** — "Completed on [date]" in course history
3. **Social share** — "I completed [Course] on [Platform]" (POST-MVP)
4. **Progress report** — Downloadable summary of what was learned

These provide recognition without the complexity of formal certificates.

## Certificate Standards (POST-MVP)

When certificates are implemented, consider:

- **Open Badges** — Standard for digital credentials
- **Credly** — Platform for issuing and managing badges
- **LinkedIn** — Credential import
- **Mozilla Backpack** — Open badge storage

These standards ensure certificates are portable and recognized.
