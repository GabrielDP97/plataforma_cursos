# User Journeys

Complete flows for each role. Step-by-step, from entry to goal.

---

## Student Journey

### Journey 1: Discover and Enroll

```
1. LAND on homepage
   ↓
2. BROWSE course catalog (search, categories)
   ↓
3. CLICK on course card
   ↓
4. VIEW course detail page
   - Read description
   - See syllabus (modules/lessons)
   - Watch preview video (if available)
   - Read instructor bio
   - Check difficulty level
   - See estimated duration
   ↓
5. DECIDE to enroll
   - Click "Enroll" button
   - If free: immediate access
   - If paid: go to payment (POST-MVP)
   ↓
6. RECEIVE confirmation
   - Enrollment success message
   - Email confirmation
   - Course appears in "My Courses"
   ↓
7. OPEN course
   - Course player loads
   - See module/lesson structure
   - First lesson highlighted
```

### Journey 2: Take a Course

```
1. OPEN course from "My Courses"
   ↓
2. COURSE PLAYER loads
   - Current progress shown
   - Continue where left off (or start from beginning)
   ↓
3. SELECT lesson
   - Click on lesson in sidebar
   ↓
4. CONSUME content
   - Watch video (if video lesson)
   - Read text (if text lesson)
   - View code snippets
   - Download resources
   ↓
5. MARK as complete
   - Click "Mark Complete" button
   - Progress updates
   ↓
6. NAVIGATE to next lesson
   - Click "Next Lesson" or select from sidebar
   ↓
7. REPEAT until module complete
   - All lessons in module done
   - Module shows 100%
   ↓
8. CONTINUE to next module
   - Or take module assessment (POST-MVP)
```

### Journey 3: Track Progress

```
1. OPEN dashboard
   ↓
2. VIEW enrolled courses
   - Course cards with progress bars
   - "Continue" button on each
   ↓
3. CLICK on specific course
   ↓
4. VIEW detailed progress
   - Module-by-module breakdown
   - Completed lessons (checkmarks)
   - Remaining lessons
   - Estimated time to complete
   ↓
5. IDENTIFY next action
   - Where to pick up
   - What's left to do
```

### Journey 4: Complete Course (POST-MVP)

```
1. FINISH last lesson
   ↓
2. COMPLETE all exercises (POST-MVP)
   - Submit all assignments
   - Get them reviewed
   ↓
3. PASS all quizzes (POST-MVP)
   - Take final assessment
   - Achieve passing score
   ↓
4. RECEIVE completion notification
   - "Congratulations!" message
   - Certificate available
   ↓
5. DOWNLOAD certificate
   - PDF with completion details
   - Share on LinkedIn (POST-MVP)
```

### Journey 5: Join Live Class (POST-MVP)

```
1. SEE live class on calendar
   - Upcoming class notification
   - Class details: time, instructor, link
   ↓
2. JOIN at scheduled time
   - Click "Join Class" button
   - Enters virtual classroom
   ↓
3. PARTICIPATE
   - Watch instructor video/screen
   - Type in chat
   - Ask questions
   ↓
4. LEAVE class
   - Click "Leave" or class ends
   ↓
5. ACCESS recording (POST-MVP)
   - Recording available after class
   - Review what was covered
```

## Instructor Journey

### Journey 1: Create a Course

```
1. LOGIN as instructor
   ↓
2. GO to instructor dashboard
   - See existing courses
   - Click "Create Course"
   ↓
3. FILL course details
   - Title
   - Description
   - Thumbnail image
   - Category
   - Difficulty level
   - Estimated duration
   ↓
4. SAVE as draft
   - Course created but not visible
   ↓
5. BUILD structure
   - Add modules
   - Add lessons to modules
   - Reorder as needed
   ↓
6. ADD content to lessons
   - Write text
   - Upload videos
   - Add code snippets
   - Upload resources
   ↓
7. PREVIEW course
   - See as student would see
   - Check for errors
   ↓
8. PUBLISH
   - Course becomes visible in catalog
   - Students can enroll
```

### Journey 2: Manage Content

```
1. OPEN course in instructor view
   ↓
2. NAVIGATE to specific lesson
   ↓
3. EDIT content
   - Modify text
   - Replace video
   - Add new blocks
   - Remove blocks
   ↓
4. SAVE changes
   - Changes live immediately
   - No re-publishing needed
   ↓
5. VERIFY
   - Preview as student
   - Check all blocks render correctly
```

### Journey 3: Track Students (MVP)

```
1. OPEN course management
   ↓
2. VIEW enrolled students
   - List of students with enrollment date
   - Total count
   ↓
3. VIEW progress overview
   - Overall completion rates
   - Per-module breakdown
   ↓
4. IDENTify struggling students
   - Low completion rates
   - Long time since last activity
   ↓
5. TAKE action
   - Send announcement (MVP)
   - Reach out (POST-MVP: DM)
```

### Journey 4: Review Exercises (POST-MVP)

```
1. OPEN exercise management
   ↓
2. VIEW pending submissions
   - List of students who submitted
   - Submission timestamp
   ↓
3. SELECT submission
   ↓
4. REVIEW student's work
   - Download file or view text
   - Compare to requirements
   ↓
5. PROVIDE feedback
   - Write comments
   - Assign grade (optional)
   ↓
6. MARK as reviewed
   - Student notified
   - Submission status updated
```

### Journey 5: Schedule Live Class (POST-MVP)

```
1. OPEN course management
   ↓
2. GO to live classes section
   ↓
3. CREATE new live class
   - Title
   - Date and time
   - Duration
   - Description
   ↓
4. SET recurrence (optional)
   - Weekly
   - Specific dates
   ↓
5. CONFIRM
   - Class appears on calendar
   - Students notified
   - Meeting link created (or manual link added)
```

## Journey Friction Points

### Student Friction

| Point | Impact | Mitigation |
|-------|--------|------------|
| Registration form too long | Abandonment | Minimal fields: email, password, name |
| Course discovery unclear | Low enrollment | Good search, categories, recommendations |
| Video buffering | Frustration | Adaptive streaming, CDN |
| Can't find where they left off | Confusion | "Continue" button, progress indicator |
| No feedback on progress | Demotivation | Clear progress bars, completion celebrations |

### Instructor Friction

| Point | Impact | Mitigation |
|-------|--------|------------|
| Course creation too complex | Abandonment | Step-by-step wizard |
| Video upload too slow | Frustration | Chunked upload, progress indicator |
| Can't see student engagement | Blind teaching | Analytics dashboard |
| No way to communicate | Disconnection | Announcements, comments |
| Content organization confusing | Poor structure | Clear module/lesson hierarchy |

### Admin Friction

| Point | Impact | Mitigation |
|-------|--------|------------|
| Can't see platform health | Flying blind | Dashboard with key metrics |
| User management tedious | Wasted time | Bulk operations, search |
| No audit trail | Security risk | Activity logs |
| Configuration scattered | Confusion | Centralized settings |

## MVP Journey Priority

### Must Work in MVP

1. Student: Register → Login → Discover → Enroll → Take Course → Track Progress
2. Instructor: Login → Create Course → Build Content → Publish → View Students
3. Admin: Login → View Dashboard → Manage Users → Manage Courses

### Can Be粗糙 in MVP

- Video player (basic works)
- Course discovery (search works, no recommendations)
- Progress tracking (basic percentage)
- Student management (list view)

### Can Wait

- Live classes
- Assignments and quizzes
- Comments and discussion
- Direct messages
- Calendar
- Certificates
- Payments
