# Official Curriculum Research — DAM & DAW First Year

## Purpose

This directory contains the official curriculum research for the first year of:
- **Técnico Superior en Desarrollo de Aplicaciones Multiplataforma (DAM)**
- **Técnico Superior en Desarrollo de Aplicaciones Web (DAW)**

**Jurisdiction:** Andalucía, España
**Academic Year:** 2026/2027
**Key Finding:** DAM and DAW share **identical** first-year modules. The only difference is in pedagogical orientation references.
